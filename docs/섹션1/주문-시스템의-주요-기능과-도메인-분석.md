## 주문 시스템의 주요 기능과 도메인 분석
주문 시스템의 도메인 이벤트를 정리한다

### 도메인 전제
여러 판매자가 입점하는 오픈마켓형 커머스로 가정

+ 플랫폼은 거래를 중개하고 수수료를 받는다
+ 상품 정보와 재고는 판매자가 관리한다
+ 플랫폼은 주문을 접수하고 결제를 대행하며 정산으로 판매자에게 대금을 지급한다

### 주문 성공
+ 주문이 접수
+ 재고가 예약
+ 결제가 승인
+ 주문이 확정

### 주문 실패 - 재고 부족
+ 주문이 접수
+ 재고 예약에 실패
+ 주문이 거절

### 주문 실패 - 결제 실패
+ 주문이 접수
+ 재고가 예약
+ 결제가 거절
+ 재고 예약이 해제
+ 주문이 거절

### 취소
+ 주문이 취소
+ 결제 취소가 요청
+ 결제가 취소
    - PG 승인 취소 완료
+ 재고 예약이 해제
    - 보상 트랜잭션을 통한 처리
+ 환불이 완료
    - 카드 결제라면 0-3 영업일 후 환불 여부 확인 필요

### 정산
+ 주문이 정산
