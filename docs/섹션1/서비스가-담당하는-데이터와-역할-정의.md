## 각 서비스가 담당하는 데이터와 역할 정의

### 역할 기준
+ 하나의 데이터는 하나의 컨텍스트만 소유한다
    - 쓰기 권한이 한 곳에만 존재한다
+ 다른 컨텍스트는 ID로만 참조한다
    - 다른 컨텍스트 데이터를 가지고 있지 않는다
+ 예외 : 시점이 중요한 값은 복사한다 (스냅샷)

|컨텍스트|소유 데이터|다른 컨텍스트에서 참조하는 방식|
|---|---|---|
|주문|주문, 주문항목, 주문상태|주문ID|
|상품|상품정보, 가격, 판매상태, 재고수량|상품ID|
|결제|결제, 결제상태, PG 거래번호, 환불|결제ID|
|정산|정산배치, 정산내역, 수수료, 지급상태|정산ID|

상품 가격은 프로모션, 이벤트나 쿠폰 발급 등으로 변경될 수 있다.  
주문항목이 상품 ID만 들고 현재 가격을 조회하면 프로모션 종료 후, 과거 주문 내역의 금액이 달라진다.
따라서 주문 컨텍스트가 자신의 데이터로 소유한다.

|데이터|소유|복사본을 갖는 곳|복사 이유|
|---|---|---|---|
|상품명, 단가|상품|주문, 주문항목|주문 시점 가격 고정|
|판매자 상호|판매자|주문|거래 당시 상대방 기록|
|주문 총액|주문|결제|승인 시점 가격 고정|
|거래액|주문|정산|집계 시점 가격 고정|
